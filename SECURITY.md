# Security Policy

## Supported Versions

Only the latest version of Cyber CTF Generator is supported.

## Reporting a Vulnerability

If you discover a security vulnerability, please use GitHub Security Advisories or open a private vulnerability report.

Please do not publicly disclose security issues before remediation.

## Scope

This project includes:

- Infrastructure generation
- pfSense automation
- Zabbix deployment
- MariaDB deployment
- Wazuh deployment
- Security monitoring components

## Security Commitment

We aim to:

- Keep dependencies up to date
- Use automated security scanning (CodeQL, Dependabot)
- Review reported vulnerabilities promptly
- Apply security fixes in future releases
